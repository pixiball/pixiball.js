# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |

## Reporting a Vulnerability

Report vulnerabilities privately through
[GitHub security advisories](https://github.com/pixiball/pixiball.js/security/advisories/new),
or by contacting the maintainers of the [pixiball organization](https://github.com/pixiball).

Please do not open a public issue for a security problem.
